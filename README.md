# Генератор мета-промптов для преподавателя

Одностраничный веб-инструмент для преподавателей ИТ-дисциплин (по умолчанию — ООП).
Собирает стандартизированный мета-промпт для ИИ-ассистента: задания трёх уровней
с локальным контекстом, стартовый код с ошибкой, тесты, рубрика на 10 баллов
и вопросы для устной защиты. Методика: ИИ создаёт черновик, преподаватель проверяет.

Инструмент ничего не отправляет в ИИ и не хранит данные: он только собирает текст промпта.
Не вводите персональные данные студентов.
